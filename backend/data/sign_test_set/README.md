# Custom sign test set

A small in-house set for end-to-end testing of the sign pipeline without
depending on WLASL video URLs, most of which are now dead.

## Layout
One sub-directory per sign label, each containing short .mp4 clips:
  hello/  yes/  no/  help/  stop/  ...

Record roughly 5 clips per sign. Note in the report that a single signer
does not represent the diverse signing population, as Bragg et al. (2021)
document, so results describe this recording setup only.

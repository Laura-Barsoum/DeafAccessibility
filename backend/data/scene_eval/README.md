# Scene captioning spot-check set

Used by `backend/scripts/eval_blip_scene.py`.

Drop 5 to 10 representative JPEG photographs here (kitchen, living room,
desk, person at a table, and so on). BLIP is generative, so the script
reports caption text plus latency for qualitative inspection rather than
an accuracy score. Do not include images of identifiable people without
their consent.
